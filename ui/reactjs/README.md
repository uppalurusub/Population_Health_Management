# Population Health Management – React TypeScript Application

A modern React.js and TypeScript frontend application for **Population Health Management, Patient Stratification, and Clinical Risk Assessment**.

The application captures comprehensive patient demographic, clinical, laboratory, lifestyle, social determinant, and healthcare utilization information and submits the patient profile to a FastAPI Population Health API.

The API response is transformed into a structured healthcare dashboard displaying:

* Population Segment
* Patient Risk Assessment
* Care Gaps
* Recommended Interventions
* Multi-Agent Findings
* Population Health Summary

---

## Overview

The **Population Health Management Application** provides a user-friendly interface for healthcare professionals, population health teams, care managers, and clinical analytics users to assess patient risk and identify appropriate care interventions.

The application integrates with the following FastAPI endpoint:

```text
POST http://127.0.0.1:8000/population-health/stratify
```

The frontend collects patient information and submits a JSON request to the Population Health API.

The API performs patient stratification and returns population health analytics, risk scores, care gaps, intervention recommendations, and agent-generated clinical findings.

## Application Components

### `App.tsx`

The root application component.

Responsibilities:

* Maintains patient request state
* Maintains API response state
* Manages loading state
* Handles API errors
* Calls the patient stratification API
* Coordinates the request and response components

Primary application state:

```typescript
const [request, setRequest] = useState<PatientRequest>(
  SAMPLE_PATIENTS.lowRisk
);

const [response, setResponse] =
  useState<PopulationHealthResponse | null>(null);

const [loading, setLoading] = useState(false);

const [error, setError] = useState("");
```

The patient stratification workflow is initiated using:

```typescript
const handleSubmit = async () => {
  setLoading(true);
  setError("");
  setResponse(null);

  try {
    setResponse(await stratifyPatient(request));
  } catch (err) {
    setError(
      err instanceof Error
        ? err.message
        : "Unable to stratify patient."
    );
  } finally {
    setLoading(false);
  }
};
```

### `populationHealthApi.ts`

Provides the Population Health API integration.

API endpoint:

```text
/population-health/stratify
```

The application performs the following request:

```typescript
httpClient.post<PopulationHealthResponse>(
  STRATIFY_ENDPOINT,
  request
);
```

Complete API function:

```typescript
export async function stratifyPatient(
  request: PatientRequest
): Promise<PopulationHealthResponse> {
  try {
    const { data } =
      await httpClient.post<PopulationHealthResponse>(
        STRATIFY_ENDPOINT,
        request
      );

    return data;
  } catch (error) {
    if (axios.isAxiosError(error)) {
      if (!error.response) {
        throw new Error(
          "Unable to connect to http://127.0.0.1:8000/population-health/stratify. Verify the FastAPI service and CORS configuration."
        );
      }

      const detail = error.response.data?.detail;

      throw new Error(
        typeof detail === "string"
          ? detail
          : `Population Health API request failed with status ${error.response.status}.`
      );
    }

    throw error;
  }
}
```

## FastAPI CORS Configuration

If the frontend displays the following error:

```text
Unable to connect to http://127.0.0.1:8000/population-health/stratify.
Verify the FastAPI service and CORS configuration.
```

Verify that the FastAPI server is running.

Also configure FastAPI CORS middleware.

Example:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
        "http://127.0.0.1:5173",
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

For local development only, CORS can be temporarily configured as:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=False,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

Use restricted frontend origins in production environments.

## Error Handling

The application supports several error scenarios.

### Backend Not Running

```text
Unable to connect to http://127.0.0.1:8000/population-health/stratify.
Verify the FastAPI service and CORS configuration.
```

Verify the FastAPI service:

```bash
uvicorn main:app --reload
```

### CORS Error

Add the React frontend origin to the FastAPI CORS configuration.

### API Validation Error

FastAPI validation errors may occur when the frontend request structure does not match the backend Pydantic request model.

Verify:

* Property names
* Numeric values
* Boolean values
* Required fields
* Nested object structures

### Request Timeout

The Axios timeout is configured as:

```typescript
timeout: 120000
```

This represents a two-minute API timeout.

If the backend executes multiple AI agents, review backend processing time if requests exceed this limit.

```env
VITE_API_BASE_URL=http://127.0.0.1:8000

```

```typescript
httpClient.interceptors.response.use(
```
